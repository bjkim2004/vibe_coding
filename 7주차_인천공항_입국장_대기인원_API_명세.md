# ✈ 인천공항 입국장별 대기인원 정보 서비스

터미널 구분값을 검색 조건으로 하여 **인천공항 입국장별(A, B, C, D, E,
F)** 대기인원, 터미널구분, 공항코드, 비행기도착게이트, 내국인, 외국인,
도착예정시간, 도착실제시간 등의 정보를\
**현재시간 기준 -2시간 \~ +2시간** 범위 내에서 조회할 수 있는 입국장
현황 정보 서비스입니다.


## 🔗 API 기본정보

-   **요청주소 (Request URL)**\
    `http://apis.data.go.kr/B551177/StatusOfArrivals/getArrivalsCongestion`

-   **서비스URL (Service URL)**\
    `http://apis.data.go.kr/B551177/StatusOfArrivals`
